# mind-service（心智体 AI 服务）

按《方案定稿.md》实现的单用户"心智体"服务。模型 = DeepSeek API 调用。

## 启动

```
双击 start.bat
```
或手动：
```
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## 浏览器界面

启动后直接打开 **http://127.0.0.1:8000/** 即可使用：

- **对话**：气泡聊天（Enter 发送，自动带 20 轮历史）
- **状态**：她的情绪/内部时钟/认知网络/目标
- **影子审阅**：她排练过的主动消息，标记"喜欢/会烦"
- **设置**：主动对话开关、影子模式、日预算、静默时段；人格与信念锚点展示
- **日志**：后台日志实时查看（报错看这里）

## 健康检查

```
GET http://127.0.0.1:8000/v1/health
```

## 目录

- `app/` — 业务模块（config / logging / main；decisions、memory、persona 等随阶段加入）
- `data/logs/mind.log` — 运行日志（文件轮转，报错看这里）
- `.env` — 你自己的密钥配置（不入库）

mind-service（心智体 AI 服务）项目简介
 
一、项目定位
 
mind-service 是一个单用户心智体（Mind Entity）AI 服务，基于 DeepSeek 大模型 API 构建。项目聚焦于回答一个核心问题：如何构建一个具备内在状态、主动行为与价值约束的智能体，而非单纯的问答工具。
 
系统以"主体化"为设计取向，通过状态持久化、常驻运行、价值约束与主动机制，实现一个可长期相处、可审计、可演进的 AI 服务。
 
二、设计目标
 
- 去工具化：将智能体定位为对等交互主体，而非指令执行器
​
- 内在一致性：通过人格包、原则约束与信念锚点，保证行为长期稳定、不可被对话漂移
​
- 诚实优先：认知边界内如实应答，未知领域明确表态，拒绝编造
​
- 可用性保障：三级降级机制确保极端条件下的可服务性
​
- 可审计：决策过程、状态变化、主动行为全程留痕
 
三、系统架构（9 个功能层 / 16 个模块）
 
1. 数据与配置层：SQLite（WAL 模式，35 张表）作为唯一持久化源；环境配置；全量结构化日志
​
2. 常驻运行层：60 秒心跳循环、内稳态预算管理、静默规划、检查点 / 回滚、健康自检与长期维护
​
3. 决策引擎层：每轮完整决策（无直通捷径）、预期自由能 G 最小化、红线拒绝、五步反驳、收束与观点接力
​
4. 认知与情绪层：存在图谱（7 类节点、15 种关系边）、8 情绪状态机、内部时钟、认知边界识别、七步学习闭环
​
5. 记忆层：四层记忆（情景 / 语义 / 情绪闪光灯 / 工作记忆），召回排序、周压缩，只归档不删除
​
6. 人格与原则层：人格包（身份 / 风格 / 禁区 / 模型补偿）、8 条底层原则、信念锚点版本链防漂移
​
7. 主动对话层：心跳引擎、多类触发器、影子模式演练、反馈调参
​
8. 服务与降级层：三级降级（重试 → 句法森林回响 → 纯状态码）、异步任务队列、WebSocket、技能系统
​
9. 交互层：REST + WebSocket 双通道 API，6 标签页单页前端
 
四、核心机制与亮点
 
- 内稳态能量管理：对话消耗与时间回充构成预算模型，配合疲劳光谱动态调节生成参数
​
- 决策可审计：每轮决策的 G 值分解、动作、原因全部落库，支持回溯与振荡检测
​
- 人格防漂移：信念锚点采用"提案 → 确认 → 回滚"版本链，经 50 轮对抗测试验证零改动
​
- 注入防御：红线规则代码级固化，对话不可修改；所有拒绝操作留痕可查
​
- 三级降级：LLM 故障时先重试，再基于句法森林生成状态回响，最终仅返回状态码，保障可用性
​
- 主动对话：基于时间、沉默、情绪、回归、知识缺口等多类触发器，配合影子模式与反馈调参
​
- 记忆治理：四层记忆 + 召回排序 + 周压缩，永不删除只归档
 
五、工程质量
​
- 技术栈：FastAPI / Uvicorn / SQLite（WAL）/ httpx / pydantic-settings / PyYAML，无 ORM、无前端框架
​
- 测试：覆盖注入拒绝、人格防漂移、决策套件（50 条）、记忆召回率（≥80%）、并发任务幂等等数十项验收用例
​
- 文档：代码档案由脚本自动生成，内容逐字可回溯
 
六、总结
 
mind-service 是一套以"主体化"为目标的心智体服务实现。通过常驻运行、内稳态管理、决策审计、价值约束、主动行为与多级降级，构建了一个状态一致、行为可解释、长期可演进、具备自我边界的 AI 智能体。
