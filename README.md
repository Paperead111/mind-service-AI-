# mind-service（心智体 AI 服务）

按《方案定稿.md》实现的单用户"心智体"服务。模型 = DeepSeek API 调用。

## 启动

```
双击 start.bat
```
或手动：
```
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## 浏览器界面

启动后直接打开 **http://127.0.0.1:8000/** 即可使用：

- **对话**：气泡聊天（Enter 发送，自动带 20 轮历史）
- **状态**：她的情绪/内部时钟/认知网络/目标
- **影子审阅**：她排练过的主动消息，标记"喜欢/会烦"
- **设置**：主动对话开关、影子模式、日预算、静默时段；人格与信念锚点展示
- **日志**：后台日志实时查看（报错看这里）

## 健康检查

```
GET http://127.0.0.1:8000/v1/health
```

## 目录

- `app/` — 业务模块（config / logging / main；decisions、memory、persona 等随阶段加入）
- `data/logs/mind.log` — 运行日志（文件轮转，报错看这里）
- `.env` — 你自己的密钥配置（不入库）
